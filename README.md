# Quran Recitation Tracker

A simple app to record completed Quran verses with an automatic timestamp.

## Features
- Enter a completed verse in a form.
- Automatically saves the current timestamp in this format: `DD-Mon-YYYY HH:MI AM`.
- Shows entries in descending order (newest first).

## Run locally
```bash
python app.py
```

Open `http://localhost:5000`.

## Run tests
```bash
pytest
```
